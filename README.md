Jarvis To-Do List App
About Project
This is my first ever web application project — a smart To-Do List app inspired by JARVIS AI.

It helps users manage daily tasks in a simple and interactive way.
 Features
 Add new tasks
 Delete tasks
 Mark tasks as completed
 Data saved using Local Storage
 Clean and simple UI
 Fast and lightweight
 Technologies Used
.HTML
.CSS
.JavaScript
 How to Use ?
1.Open the app
2.Enter your task
3.Click Add
4.Mark completed or delete anytime.
